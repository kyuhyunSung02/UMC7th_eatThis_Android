## 🌟 **주요 기능 (Android App)**

### 🥗 **식단 제공 서비스**

* **맞춤형 식단 추천**: AI 영양사가 개인 건강/목표에 맞는 식단 제공
* **다양한 단위**: 오늘 / 주간 / 월간 단위로 관리 가능
* **체계적 관리**: 식습관 분석 기반 균형 잡힌 식단 제안

### 💰 **시세 서비스**

* **실시간 가격 확인**: 식재료 시세 실시간 제공
* **구매 연동**: 마켓/쿠팡 등 쇼핑 플랫폼 연동
* **시세 차트**: 가격 변동 추세 확인 가능
* **합리적 소비 지원**: 경제적인 식단 구성 가능

### 📦 **구독 서비스**

* **정기 구독**: 주/월 단위 맞춤형 식단 제공
* **배송 선택**: 다양한 배송 옵션으로 편리한 이용 가능
* **지속 관리**: 장기적인 건강 관리 가능

### 🧬 **나의 건강 서비스**

* **건강 분석**: 영양 균형, 체질, 생활 습관 분석
* **변화 추적**: 체중, 신체 변화, 영양 상태 기록
* **AI 개선 플랜**: 개인 맞춤 건강 관리 플랜 제공

---

## 💡 **프로젝트 배경**

**이거먹자**는 **AI 기반 개인 맞춤 식단 관리 서비스**로,
“오늘 뭐 먹지?”라는 일상적인 고민부터 장기적인 건강 관리까지 해결하는 **AI 영양사 플랫폼**입니다.

### **해결하고자 하는 문제**

* 🍽️ **매일 반복되는 식사 고민**: “오늘 뭐 먹지?”를 AI가 해결
* 🥦 **건강 관리의 어려움**: 식단 균형·영양 분석을 전문가처럼 제공
* 📉 **경제적 부담**: 실시간 시세 반영으로 합리적 소비 지원
* 📊 **장기 관리 부족**: 구독 서비스와 건강 기록으로 꾸준한 관리 가능

### **핵심 가치**

* **🤖 AI 기반**: 개인 맞춤 식단과 건강 분석 제공
* **🥗 건강 중심**: 균형 잡힌 식단으로 생활습관 개선
* **💰 합리적 소비**: 시세 정보를 통한 경제적 선택
* **📈 지속 가능성**: 구독 서비스와 건강 추적을 통한 장기 관리

---

## 📊 **기대 효과**

1. **⏰ 시간 절약**: 식단 고민 없이 AI가 자동 추천
2. **🥦 건강 증진**: 맞춤 영양 관리로 생활습관 개선
3. **💰 비용 절감**: 실시간 시세 반영으로 경제적 식단 구성
4. **📈 장기적 효과**: 구독 + 건강 기록으로 꾸준한 관리 가능
